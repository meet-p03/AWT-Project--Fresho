Fresho Project Specifications

Design System Tokens

  • --primary: #17703A (Forest Green)
  • --dark-green: #0D3B22 (Headings & Accent)
  • --lime-accent: #C6E35A (Highlights & Badges)
  • --bg-page: #F6F9F2 (Light Mint Grey)
  • Produce Colors: Tomato (#E4572E), Mango (#F4A62A), Leaf (#3E9B4F), Potato (#C9A06A)
  • Typography: Plus Jakarta Sans (400 to 800 weights)
  • Radius: 20px Cards, 52px Pill Buttons

Component Library

  • .f-btn: Pill button (52px high) with CSS diagonal shine animation
  • .f-btn-add: Circular 36px (+) button with CSS pulsing ring
  • .f-card: 20px rounded card with 1px border (#E3EADB)
  • .status-pill: Status tags (Pending, Confirmed, Shipped, Delivered)
  • .bottom-nav: Fixed 64px customer navigation bar
  • .tab-group: Segmented toggle tabs

AngularJS Suggested Route Map

  • /splash → Splash onboarding view
  • /role-select → Role selection
  • /signup → Account registration
  • /login → Auth view
  • /home → Customer home feed
  • /product/:id → Product details modal/view
  • /cart → Shopping cart
  • /checkout → 3-Step Checkout
  • /orders/:id → Order tracking view
  • /farmer/dashboard → Farmer earnings & orders
  • /farmer/products/new → Add produce item
  • /admin/dashboard → Admin verifications & stats
